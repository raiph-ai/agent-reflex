Agent Reflex GitHub

Hermes Agent integration

Fast structured decision hooks for autonomous agents.

Route, guard, and score agent actions before the big model thinks. Agent Reflex sends obvious decisions to instant rules, local/private decisions to low-cost reflex models like Cactus, and only escalates to full LLMs when the work actually needs them.

Route

Classify incoming tasks by project, intent, priority, and recommended agent.

Guard

Preflight risky work like publishing, production writes, destructive changes, credentials, and financial actions.

Validate

Check whether the final output satisfies requirements before the agent declares success.

Measured local benchmark

Why burn a full reasoning turn on a traffic light?

In a local benchmark for a production-publish risk decision, Agent Reflex avoided a main-model call and returned structured guidance dramatically faster.

~130 ms Built-in deterministic rules. Fastest path for obvious safety gates.
~635 ms Local Cactus / Needle reflex model. Private, local, and roughly 44x faster than the main model test.
~0.43 sec Combined route + risk + skill preflight in one local Cactus call. Roughly 64x faster than the main model test.
~27.8 sec Main Hermes reasoning model doing the same small classification job. 
Obvious safety decision  → rules
Local/private reflex     → Cactus
Typed cloud reflex       → Jev / future providers
Complex reasoning        → full LLM

Benchmark context: local macOS test, Agent Reflex CLI, Cactus/Needle on 127.0.0.1:8088, Hermes main-model comparison using the same risk-classification task. Exact timings vary by machine and provider; the architectural point is stable: do not spend premium reasoning on repeatable traffic-light decisions.

Decision escalation logic

Local first. Reflex second. Full LLM only when needed.

1Task arrives
2Rules run first for instant safety guardrails
3One bundled reflex call to Cactus locally or Jev in the cloud
4Escalate to the full LLM only for complex reasoning or low confidence
User task
  ↓
Built-in rules baseline
  ↓
One bundled reflex call: route + risk + skill
  ├─ local/private → Cactus
  └─ typed cloud   → Jev / future providers
  ↓
Full LLM only if the decision needs deeper reasoning

Quickstart

git clone https://github.com/raiph-ai/agent-reflex.git
cd agent-reflex
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .
agent-reflex risk --input examples/risk-production-write.json

Safe Hermes install

The bundled Hermes skill is designed to fail safe. If the CLI is absent, times out, or returns invalid JSON, Hermes continues with a manual fallback checklist instead of breaking.

agent-reflex-hermes-install --dry-run
agent-reflex-hermes-install --target "$HERMES_HOME/skills"
  • Dry-run support before writing files.
  • No overwrite unless --force is passed.
  • Backup created as agent-reflex.bak before replacement.
  • Temporary staging prevents half-installed skills.

Decision envelope

Every decision returns a stable JSON envelope so Hermes can reason over the result predictably.

{
  "decision": "requires_approval",
  "confidence": 0.9,
  "provider": "rules",
  "thresholds": {},
  "fallback": false,
  "risk_level": "high",
  "requires_human_approval": true,
  "requires_verification": true
}

Provider roadmap

The default provider is dependency-free rules. Jev/TypeSafe, Cactus, and OpenAI-compatible adapters are reserved behind safe fallbacks so missing credentials never break Hermes.

agent-reflex risk --provider rules --input task.json
agent-reflex risk --provider jev --input task.json
agent-reflex validate --provider openai-compatible --input result.json

Provider policy

Phase II adds auto mode: Agent Reflex can try Cactus, Jev, OpenAI-compatible providers, and deterministic rules in a configurable order. Rules remain the terminal fallback and risk guardrail.

export AGENT_REFLEX_PROVIDER=auto
export AGENT_REFLEX_PROVIDER_ORDER="cactus,jev,openai-compatible,rules"
agent-reflex risk --input examples/risk-production-write.json

Read provider policy docs

Automatic Hermes preflight

Enable advisory automatic mode to have Hermes run route/risk/skill guidance before normal work when the Agent Reflex skill is loaded.

export AGENT_REFLEX_HERMES_AUTO_ENABLED=true
agent-reflex preflight --input task.json
